# Agent entry point

Read `How to Set Up.md` before setup or runtime changes. Dhan is the preferred
and default broker; FYERS is optional. All trading is paper only.

This checkout is standalone. Do not depend on another `/opt` project, credentials
from an old VPS, or production services to run it locally. Use the explicit demo
for credential-free validation; never present demo prices as live broker data.

Run the documented tests for changes. Keep credentials, tokens, local ledgers,
venvs and generated browser artifacts out of Git. Preserve existing paper state.
